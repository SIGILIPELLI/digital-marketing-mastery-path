# 06 · On-Page SEO

On-page SEO is optimising each individual page so search engines (and people) instantly understand what it's about and why it's the best answer. You'll apply it to the pages from your keyword map.

## 1. Title tag and meta description

1. The **title tag** is the blue clickable headline in search results. Put the primary keyword near the start and keep it around 50–60 characters: `Office Catering in Pune | Hot, On-Time, GST Invoice – Chai Corner`.
2. Every page needs a **unique** title.
3. The **meta description** (around 150–160 characters) doesn't directly affect ranking but influences clicks: `Snacks and meals for 20–100 people, delivered hot across Baner, Aundh & Hinjewadi. Per-head pricing from ₹120. Get a quote in 30 minutes.`
4. In WordPress, set these with an SEO plugin such as Yoast or Rank Math; in Wix/Shopify, use the page's SEO settings.

## 2. Headings and content

1. One **H1** per page containing the primary keyword (often the visible page headline).
2. Use **H2/H3** subheadings for sections, naturally including secondary keywords and questions ("What's included in office catering?").
3. Answer the search intent fully and early — price, area, minimum order — then add depth.
4. Write for people: short paragraphs, bullet points, real details (menu items, photos, numbers). Don't repeat the keyword unnaturally; Google understands synonyms.
5. Show **experience and trust** (Google's E-E-A-T idea: experience, expertise, authoritativeness, trust): real photos, named testimonials, address and contact details, author names on articles.

## 3. URLs, links and images

1. Short, readable URLs: `/office-catering-pune`, not `/page?id=123`.
2. **Internal links**: link from related pages using descriptive anchor text ("see our office catering menu"). This helps Google discover pages and understand topics.
3. Link out to authoritative sources when useful.
4. Images: descriptive file names (`office-snack-box.jpg`), **alt text** describing the image ("Snack box with samosa, sandwich and chai for office meetings"), compressed and sized correctly.

## 4. Structured data and snippets

1. **Schema markup** (structured data) tells Google explicit facts: `LocalBusiness` (address, hours), `Product`, `FAQPage`, `Review`, `Article`.
2. Many plugins add schema automatically; test pages with Google's **Rich Results Test**.
3. A clear FAQ section helps you appear in "People also ask" style results.

## Cheat sheet

| Element | Rule |
|---|---|
| Title tag | Primary keyword first, ~55 chars, unique |
| Meta description | ~155 chars, benefit + CTA |
| H1 | One per page, includes keyword |
| H2/H3 | Sections and questions |
| URL | Short, keyword, hyphens |
| Internal links | Descriptive anchor text |
| Images | File name + alt text + compressed |
| Schema | LocalBusiness, FAQ, Product; test in Rich Results Test |

## How It Actually Works

Search engines read a page's structure the way a fast human reader skims: title and H1 for the main topic, headings for subtopics, links for relationships, structured data for unambiguous facts. Clear structure lowers the effort for Google to classify the page and for people to find their answer — and pages that satisfy searchers quickly tend to earn better engagement and links over time. Keyword stuffing fails because modern ranking systems model meaning; they reward covering the topic thoroughly in natural language.

## Exercise

Take the most important page from your keyword map. Write its title tag, meta description, H1, at least four H2s, a 400-word draft body with real details, three internal links, alt text for two images, and a five-question FAQ. If the page is live, re-check it in URL inspection after publishing.
